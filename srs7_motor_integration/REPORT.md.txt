# СРС №7
## Виртуальный стенд Arduino: интеграция HC-SR04 с драйвером двигателя L298N (Часть 1)

### 1. Цель работы

Цель работы — разработать виртуальную схему на основе Arduino Uno, ультразвукового датчика HC-SR04 и драйвера двигателя L298N. Реализовать управление направлением и скоростью двигателя в зависимости от расстояния до препятствия.

### 2. Используемые компоненты

- Arduino Uno
- Ультразвуковой датчик HC-SR04
- Драйвер двигателя L298N
- Кнопка управления
- Три светодиода: красный, жёлтый и зелёный
- Три резистора по 220 Ом
- Соединительные провода
- Онлайн-симулятор Wokwi

### 3. Сборка схемы

В симуляторе Wokwi была собрана схема с использованием Arduino Uno. Датчик HC-SR04 подключён к цифровым выводам D9 (TRIG) и D10 (ECHO).

Кнопка подключена к D2 и GND. Для её работы используется режим INPUT_PULLUP.

Светодиоды подключены через резисторы 220 Ом: красный — к D13, жёлтый — к D12, зелёный — к D11.

Драйвер L298N подключён к Arduino следующим образом:

- IN1 — D5
- IN2 — D6
- ENA — D3 (PWM)
- 5V — 5V Arduino
- GND — GND Arduino

### 4. Принцип работы программы

При отпущенной кнопке измерения приостанавливаются, светодиоды выключаются, а управляющий сигнал двигателя устанавливается в режим остановки.

При нажатой кнопке Arduino измеряет расстояние до препятствия и выбирает режим:

- Менее 20 см — красный светодиод, остановка, PWM = 0.
- От 20 до 50 см включительно — жёлтый светодиод, движение вперёд, PWM = 120.
- Более 50 см — зелёный светодиод, движение вперёд, PWM = 255.

Если датчик не возвращает сигнал, программа выводит сообщение Sensor timeout и отключает управление двигателем.

### 5. Результаты испытаний

| Условие | Результат |
|---|---|
| Кнопка отпущена | Светодиоды выключены |
| 10,10 см | Красный светодиод, STOP, PWM = 0 |
| 20 см | Жёлтый светодиод |
| 36,12 см | Жёлтый светодиод, FORWARD, PWM = 120 |
| Установлено 50 см, измерено 50,13 см | Зелёный светодиод, так как измеренное значение больше 50 см |
| 70,21 см | Зелёный светодиод, FORWARD, PWM = 255 |
| Отсутствует сигнал ECHO | Sensor timeout, светодиоды выключены |

Проверка выполнена в симуляторе Wokwi. Работа светодиодов, датчика и программных режимов подтверждена наблюдениями.

Ограничение: физическое вращение DC-двигателя не проверялось, поскольку в используемой схеме отсутствует симулируемая модель двигателя. Поэтому результаты подтверждают программное управление выводами драйвера, но не фактическую работу моторной нагрузки.

### 6. Использование искусственного интеллекта

Во время выполнения задания искусственный интеллект использовался для объяснения подключения компонентов, проверки файла diagram.json и подготовки программного кода.

Предложенные решения проверялись в симуляторе. При обнаружении неточностей в подключениях схема исправлялась. Результаты испытаний оценивались по фактическим показаниям Serial Monitor и состоянию светодиодов.

### 7. Заключение

В ходе самостоятельной работы была создана виртуальная схема на базе Arduino Uno с датчиком HC-SR04 и драйвером L298N. Разработана программа, которая определяет расстояние до препятствия и изменяет управляющий PWM-сигнал в зависимости от измеренного значения.

Проверены три основных режима работы, управление кнопкой и обработка отсутствия сигнала датчика. Полученные результаты соответствуют заданной логике программы. Для полноценной проверки работы двигателя потребуется подключить и испытать моторную нагрузку.
