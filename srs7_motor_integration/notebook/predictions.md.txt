# Прогнозируемые результаты испытаний

Перед проверкой схемы были определены ожидаемые результаты работы программы.

| Условие | Ожидаемый результат |
|---|---|
| Кнопка отпущена | Все светодиоды выключены, PWM = 0 |
| 10 см | Красный светодиод, PWM = 0 |
| 20 см | Жёлтый светодиод, PWM = 120 |
| 35 см | Жёлтый светодиод, PWM = 120 |
| 50 см | Жёлтый светодиод, PWM = 120 |
| 70 см | Зелёный светодиод, PWM = 255 |
| Нет сигнала датчика | Sensor timeout, PWM = 0 |
| IN1 и IN2 поменяны местами при 35 см | Команда обратного направления, PWM = 120 |

Примечание: фактическое измерение может немного отличаться от установленного расстояния. Например, при установленных 50 см датчик показал 50,13 см, поэтому включился зелёный светодиод.

Физическое вращение двигателя в данной симуляции не проверялось.
